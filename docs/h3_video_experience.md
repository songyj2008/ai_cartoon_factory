# H3 视频 OK 提示词经验库

在设置 → 网页 LLM → 视频 OK 经验分析中选择网页服务，可跟随全局或独立选择。
点击“标记视频 OK”后先保存标记，再后台提交该视频版本的历史提示词中“主体定义”和“详细镜头描述”，以及成片实际总时长、项目、集数、分段、版本信息。
只发送文字，不上传视频、音频、图片或其他文件，不要求网页具备附件能力。无需为此升级扩展。

LLM 分析台词与时长安排、动作和情绪如何辅助对白、Shot 衔接，以及可能减少乱说话的写法。结果明确属于用户认可提示词的经验分析，不是逐句音画核验。

经验保存在 assets/learning/h3_video_experience.sqlite3，不随任务清理删除。相同版本不重复分析；取消 OK 会停用对应版本经验并取消未完成分析，迟到结果不能重新启用。
已归档集数也可标记和取消视频 OK、提交分析；剧情、提示词、时长修改和重新生成仍只读。

完整生成／重新规划提示词、“反馈并修正”，以及“重新规划时长”，现在都会最多参考三个简短 OK 案例。检索同时查看当前实际发言者、该发言者的音频指纹和镜头对白结构；整段音频有交集不等于当前说话人的音色相同。相同音色的直接对白案例不会挤掉所有“无对白镜头后开始对白”的结构案例，也保留当前发言者的相关记录。匹配程度相同时优先同项目，跨项目仅在人物或结构有匹配时参考。

案例包含项目、集数、分段、成片版本、原提示词片段及匹配说明，历史素材编号仅用于理解案例。时间均注明属于提示词计划或成片总长，不当作逐句发声实测。已人工标记 OK、但后台文字分析失败的记录仍可提供原提示词；旧版视频附件分析不混入纯文本经验。读取经验使用只读连接，不触发分析、建表或重新生成。

经验只辅助模型创作，不覆盖当前编辑稿、对白、参考素材、静默镜头或用户约束，也不要求照搬历史动作。“重新规划时长”仍只改时间值；要调整镜头声画衔接，需要从当前稿完整重新规划提示词。已有完整原生计划仍可按原逻辑复用，单纯重新提交视频不会改写提示词。

“反馈并修正”按选中的底稿与其素材检索：勾选当前编辑稿时使用当前保存稿及当前素材；否则使用成片生成快照。案例只辅助反馈指定问题及直接冲突，不授权重写其他镜头。反馈仍返回完整 revised_prompt 及修改说明；没有新增媒体附件。

继续使用“参考音色＋提示词→H3 自由生成整段音视频”。这些案例不能保证每次生成都遵守静默边界，实际结果仍须复核；没有新增预制对白或音轨拼接路径。学习任务低优先级且最多运行一个，失败不撤销 OK。
