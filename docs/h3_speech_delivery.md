# H3 逐镜声画关系

全段绑定声音身份，镜头明确当前说话人、音色参考、声源和听者状态。
无对白不等于没有环境声；未解析成功不等于无对白。
画外说话与人物出镜分别记录，电话或旁白音色不限制人物整段不得出镜。

## 提示词职责

共同创作合同见 `profiles/h3_segment_planning_rules.md`，小说分段和单段重生成共用。
概述交代事件目标；镜头中的 action 描述可见表演，dialogue/dialogues 保存唯一台词原文，
audio 描述本镜声音安排。每个整镜无人发言的镜头都必须写“本镜无对白”，并保留本镜原有的非对白声音，例如“本镜无对白，仅有脚步声”；没有指定其他声音时不编造音效。画外、电话、旁白与跨镜续说仍属于有对白，只有部分阶段无人发言时不能把全镜标成无对白。
音色身份和通用声音要求各说明一次，不通过追加表演禁令修补单次失败。
整体声音环境仅采用明确的 overall_soundscape；局部音效保留在原镜头，不再汇总为全段声音。
这些生成指引不会通过本地文本替换改写用户已有台词、动作或历史提交快照。

## 镜内阶段

普通对白继续使用 speaker / scope / line。发生句内转换时，在同一条对白上附
delivery_spans，原句不重复。range 为 Python Unicode 字符左闭右开范围；
所有阶段连续、无重叠地覆盖整句。source_type 区分声音渠道，visibility 区分
画内外，两者独立。voice_asset_id 如提供，必须是当前素材列表的稳定资产 ID。

```json
{
  "speaker": "role_b",
  "scope": "offscreen",
  "source_type": "diegetic",
  "line": "请先坐下，听我把事情说完。",
  "delivery_spans": [
    {"range": [0, 5], "visibility": "offscreen"},
    {"range": [5, 13], "visibility": "onscreen", "mouth_mode": "sync_speech",
     "transition": "镜头连续横移，将B纳入画面"}
  ]
}
```

规划器的 dialogue_refs 允许整数序号，或含 number、delivery_spans 等字段的对象。
台词仍由当前对白清单带入，不由阶段再次抄写。每个 Shot 输出 visible_roles，
空场景为 []，画外人物不能仅因发声而列入出镜列表。

编译后的阶段格式是 `发声阶段（画外）`、`发声阶段（画内，口型同步）`；
转换事件使用 `转换：…`，同句后段使用 `接续本句，…说：<d>…</d>`。
编辑器以这些明确标记恢复原句与阶段，不按相同名字或相同台词猜测合并。
跨镜续说仍使用“接着上个 Shot 继续说”，不与镜内续说混用。

## 编辑与保存

混合阶段的普通发声方式下拉框有保护，阶段通过完整提示词编辑。
修改原句导致字符范围失效时会报错，必须重新确认阶段；程序不自动裁切或补写台词。
转换默认以入画事件及原句片段描述，不固定为镜头时长的一半。
正常听者使用“不做说话口型”，闭口完全静止只用于明确的输入要求。

结构回归测试验证解析、编辑、保存和重编译关系；音色、口型与入画效果需要成片验证。
