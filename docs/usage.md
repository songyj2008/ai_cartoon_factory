# 日常使用说明

环境安装、服务配置和启动见 [Windows 指南](windows.md)。运行前准备自己的剧情或小说文本、人物参考、场景背景，以及可用的文字模型和视频生成服务。

## 推荐流程

1. 创建或选择项目，需要分集时创建剧集。确认当前项目与剧集再操作。
2. 导入角色、背景及所选模型需要的参考素材，登记角色身份、素材用途；素材属于本机数据，不随源码下载。
3. 填写项目设定、故事要求或小说原文，生成剧情与 Beats。核对对白归属、顺序、原文覆盖和事件划分。目标 Beat 数和总时长是规划目标，偏差应审阅，不代表必须机械切段。
4. 选择视频模型，生成分段候选。检查提示词、参考绑定和时长后保存。说话人变化或切镜不必自动拆成新 Beat，具体镜头写在 Shots 中。
5. 在分段全屏编辑器调整提示词、参考、镜头与声音；应用候选后还需保存。生成新候选失败时保留原结果，查看失败诊断再重试。
6. 独立段选择独立生成；连续场景由用户在编辑器或批量分组页明确分配。相同背景图并不自动代表同一连续场景。
7. 选择生成渠道并提交。每段完成准备后即可提交，不必等全部分段文字准备完成。随后在任务与视频历史中查看提交、渲染和成片，检查实际画面后再决定修正或合并。

## 连续场景与批量生成

只勾选本次需要执行的分段，再分配场景与结束状态处理方式。未勾选段不改分组、提示词、时长或状态，不自动补做任务。后段依赖同场景前驱已保存的结束状态；缺少或过期时按错误提示处理前置条件。无需等前驱视频渲染结束才准备下一段文字。

结束状态是提示词计划事实，不是自动识别成片所得。场景批次时间覆盖文字准备至视频提交，云端渲染另计；累计执行耗时不含排队与暂停。编辑器的具体保存、承接、重试与镜头操作见 [H3 编辑器说明](h3_editor_operations.md)。

## 视频反馈与重试

在全屏编辑器选择已有视频，结合对应提交提示词填写问题、时间点与期望，生成修正候选。先查看修改说明与完整提示词，再应用保存或提交新视频。历史视频不因当前稿改变而重写。

文字任务失败、云端拒绝提交、渲染失败应分别查看对应任务记录。浏览器 LLM 可能已发送成功但尚未回传；先检查任务编号与原会话，避免重复发送。刷新页面不会代替重试，也不要用全局清空处理单段完成或标签页清理问题。

## 数据存放

| 路径 | 内容 |
| --- | --- |
| `projects/` | 项目设定与选择等元数据 |
| `episodes/` | 剧集运行数据、分段和媒体 |
| `outputs/` | 无剧集项目的运行数据和输出 |
| `assets/` | 本机素材库与索引 |
| `logs/` 及运行目录内日志 | 本机诊断信息 |
| `%LOCALAPPDATA%\AICartoonFactory` | 网页任务队列、配对等本机数据 |

备份时需同时保存项目设定、素材和运行目录，单独复制一个视频不能恢复编辑状态。源码发布不包含这些目录，恢复后文件路径也须有效。
