# 任务中心一键清空

任务中心摘要右侧的“一键清空”停止并清空所有项目的文字任务、待应用候选和网页视频任务，覆盖排队、执行中、等待网页回复和已结束记录。
后端作废旧网页任务凭据，阻止旧任务创建新请求及迟到结果回填；视频任务保留已消耗额度、成片文件和生成历史。
经验库中已完成的经验保留，未完成的经验分析停止。

安装 tools/chrome_prompt_bridge-v0.4.34.zip 内的扩展并重新加载，重启项目、刷新页面。扩展收到清空信号后删除本地文字、视频及手动任务等待记录，关闭扩展创建的任务标签页，保留用户自行打开的标签页和服务配置。
离线扩展再次连接后自动同步。已发到网页的请求可能继续生成，但不再回填项目。

## 单段任务完成后的自动收尾

扩展 v0.4.39 起，每个网页文字调用的结果回传后台并确认成功后，会自动关闭该任务的扩展专用标签页。已完成的旧任务页在后续轮询时一并收尾，关闭失败会重试；后台结果和任务记录保留。未回传的结果、仍在执行的任务、用户自行打开的页面及已切换到其他会话的页面不会被清理。

这一步不调用全局“一键清空”，不会停止其他分段或清除批次进度。更新项目源码后，需要在 Chrome 扩展管理页重新加载扩展；只重启项目不会更新扩展的后台脚本。
