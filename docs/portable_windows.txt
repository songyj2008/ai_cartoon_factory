AI Cartoon Factory · Windows x64 便携版

启动
GitHub 分包下载首次安装时，先解压发布说明链接中的基础运行包，再把应用更新包解压到同一目录，合并 AI_Cartoon_Factory 文件夹。更新前从托盘退出程序并备份本机数据，后续按发布说明复用对应基础包。
1. 将整个 ZIP 解压到普通可写目录，例如 D:\AI_Cartoon_Factory。
2. 打开解压后的 AI_Cartoon_Factory 文件夹，双击 AI_Cartoon_Factory.exe。
3. 首次启动会自动创建配置和空项目。电脑缺少 WebView2 时会运行包内的微软离线安装器，请等待安装完成。
4. 点击窗口右上角关闭会收起到托盘，后台任务继续运行。点击任务栏右下角的托盘图标可恢复，右键选择「退出程序」可彻底关闭。图标可能位于「显示隐藏的图标」中。

运行环境
适用 Windows 10 / 11 64 位，使用系统自带的 .NET Framework 4.8。
包内已包含 Python 运行时、应用依赖、FFmpeg、ffprobe 和 WebView2 离线安装器。
请保留解压文件夹内的全部文件，EXE 依赖同目录的运行库和资源。

生成前配置
打开应用设置，填写自己的模型服务密钥，或连接浏览器扩展使用已登录的网页模型。
使用云端视频生成需要对应账号和额度。
使用本地视频生成需要另外准备并启动 ComfyUI、节点和模型，填写其地址及输入输出目录。
工作流模板随包附带，具体可用性取决于所配置的生成服务。
浏览器扩展位于 tools\chrome_prompt_bridge，可在 Chrome 或 Edge 的扩展管理页以开发者模式加载，随后按应用设置中的地址及配对码连接。

保存与迁移
配置位于 config.json，项目和素材保存在本文件夹内的 projects、episodes、outputs、assets。
浏览器任务数据另存于 %LOCALAPPDATA%\AICartoonFactory。
迁移到新电脑后请在设置中重新填写密钥。
出现启动问题时查看 logs\desktop.log。

WebView2 离线安装器来自微软官方分发地址
https://developer.microsoft.com/en-us/microsoft-edge/webview2/
