# H3 人物参考音色

依据本机 `F:/work/comfyui/MiniMaxH3/MiniMax H3 模型 - 使用手册.md` 的“音色克隆与迁移”和“参考素材说明”：素材应说明编号、归属和用途；音色参考不等于音频复用。音频最多 3 段，每段 2–15 秒，总时长不超过 15 秒，须配合图片或视频，总素材最多 12 项。现有 H3 validator 在工作流编译时统一验证这些限制，不静默截断自动音频。

人物素材库的 `identity.voice_reference` 是自动音色来源。只要本段人物图片匹配到 `metadata.identity_id`，就带入其已上传音频，不依赖 Beat 的 dialogue_units。音色用于已有对白，不新增对白。相同人物多图只带入一段音频。

全屏素材列表显示音频来源、时长并可试听。人物图的“自动使用人物参考音色”开关将本段选择保存在图片 metadata.voice_disabled；移除自动音频也禁用该人物的自动音色。手动音频通过下拉选择人物后，以 metadata.identity_id / voice_only 绑定，优先于该人物的自动音频。取消手动绑定后恢复通用音频用途。

保存和生成前统一调用 attach_character_voices。工作流使用本地 H3 的 <Picture N> / <Audio N> 编号；由 AssetBinder 生成编号，再由编译器写入人物音色用途。编译器维护“人物音色绑定”区块，重排素材时重建，不积累重复区块。录音转写不注入剧情提示词。工作流的 LoadAudio 必须接入对应 ref_audios 输入。

人物素材库换音频后，下一次保存/编译使用新文件；历史生成记录及旧音频文件保留。
